Morse Code Generator Readme
🔤 Morse Code Generator

A simple and real-time Morse Code Generator built using HTML, CSS, and JavaScript. This project converts normal text into Morse code (dots and dashes) instantly as the user types.

🚀 Features
Real-time text to Morse conversion
Supports:
Alphabets (A–Z)
Numbers (0–9)
Common punctuation symbols
Proper spacing:
Space between letters
/ used between words
Clean and minimal UI
🛠️ Tech Stack
HTML
CSS
JavaScript (Vanilla JS)
📂 Project Structure
project-folder/
│── index.html
│── style.css
│── script.js
⚙️ How It Works
User enters text in the textarea
JavaScript listens to input events
Each character is mapped using a Morse code object
Output is generated in real time with proper formatting
📌 Example

Input:

HELLO WORLD

Output:

.... . .-.. .-.. --- / .-- --- .-. .-.. -..
